# Project Management

Methodology used: a lightweight shared Kanban board. Each task moves from "To Do" to "In Progress", then "Done" after being tested by both teammates.

- **arvella**: engine (maze generation, game rules, collisions, ghosts, scoring, and high scores).
- **dgarrido**: display (Pygame, menus, HUD, sprites, end screens, and settings).
- **Both**: integration, testing, and delivery.
